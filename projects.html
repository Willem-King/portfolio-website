Blue River Zoo Management System Full-Stack Web Application
Software Developer

An interactive web-based facility management portal engineered for zoo operations. The system features multi-role access control tailored specifically for Visitors, Staff, and Administrators to streamline facility interactions, ticket scheduling, and animal care tracking.

Key Capabilities & Features:

  • Role-Based Access Control: Distinct interfaces and privileges for Visitors (ticket bookings, schedules), Staff (daily duties, facility updates), and Admins (system reporting, user management).
  • Dynamic Frontend Interface: Responsive JavaScript UI components providing real-time interactive scheduling and user dashboards.
  • Relational SQL Backend: Designed a structured database backend to handle user authentication, booking transactions, and facility resource allocations efficiently.

MobiVet Mobile Veterinary Database System CMPG 311 Project
Database Architect & Developer

An end-to-end relational database solution designed to expand a primary clinic's operations into semi-independent mobile veterinary care units. Built to solve resource allocation conflicts, track fleet logistics, manage patient medical histories, and process service payments.

Key Architectural Highlights:

  • Conflict Prevention & Business Rules: Designed data constraints to eliminate double-booking for shared veterinary staff, specialized vehicles, and home appointments.
  • Comprehensive Data Model: Conceptualized an ERD and Logical Schema covering 16 interrelated entities including Pet Owners, Patients, Appointments, Treatments, Vehicle Checklists, and Financial Payments.
  • Specialized Roles & Integrity Constraints: Implemented specialized supertype/subtype relationships for Staff roles (Veterinarians, Nurses, Drivers) and bridge entities for multi-service billing and staffing.
  • CMPG 311
  • Relational SQL
  • ERD Modeling
  • Logical Data Modeling
  • Integrity Constraints
